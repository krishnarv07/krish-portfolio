## Install
1. Back up the current site folder.
2. Extract this ZIP into the site folder and replace the corresponding code files.
3. Keep the existing `assetes/` folder and its `hero.jpg` / `about.jpg` images.
4. Keep `project-assets/` next to `index.html`.
5. Verify project order, banner cover visibility at desktop and mobile widths, filters, Load more / Show fewer, project dialogs, Copy email, mobile navigation, and the game.

No external UI libraries or build tools are required.
